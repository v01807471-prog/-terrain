# Проверки проекта

## Локальный запуск

Требуется Node.js 22 или совместимая версия.

```bash
npm install
npm run typecheck
npm test
npm run build
```

`npm test` компилирует только необходимые доменные модули в временный каталог `.test-dist/` и запускает их через Node.js. Сторонний test runner и дополнительные runtime-зависимости не требуются.

## Покрытие Terrain

Набор `runTerrainSelfTests()` проверяет:

- детерминизм процедурной CPU-высоты для одинаковых seed/координат и влияние seed на результат;
- детерминизм высоты, вычисленной из Blueprint-графа;
- отсутствие предварительной heightmap и ленивое выделение sparse-блоков;
- повторное использование блока, переход через границу блока и отрицательные координаты;
- освобождение блока после обратного мазка;
- разделение процедурной основы и локальной дельты, версии, dirty bounds и отписку от событий;
- выборку обоих треугольников сетки LOD0, нормаль и уклон.

Также запускается существующий набор самопроверок `runTerrainPhysicsSelfTests()` для фиксированного шага, контакта сферы с Terrain и столкновения двух сфер.

## Что пока не проверяется автоматически

Эти проверки не заменяют браузерные регрессионные сценарии редактора. Они не подтверждают работу реального WebGL-контекста, взаимодействия с панелями, полного sculpt/history workflow, GPU-передачи sparse edits или численное совпадение CPU/GPU на целевых видеокартах. Для этого нужны отдельные browser-тесты и проверка на реальном WebGL-устройстве.

## CI

GitHub Actions выполняет в указанном порядке:

1. установку зависимостей;
2. проверку TypeScript;
3. `npm test`;
4. production build через Vite.
